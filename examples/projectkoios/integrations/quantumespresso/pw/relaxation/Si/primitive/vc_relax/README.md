# Variable-cell relaxation fixture

`calculation.toml` is a static integration fixture for QE `vc-relax` loading
and rendering. It exercises ionic and cell BFGS fields, `cell_dofree = 'all'`,
and deterministic projection into the committed native input artifacts.

The values are retained source declarations, not a current workflow,
production recommendation, convergence result, or scientific acceptance
policy. This fixture grants no execution authority.
