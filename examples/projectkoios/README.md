# Package-owned examples and retained material

This tree follows public package ownership rather than defining a runnable
application:

- [`simulations/`](simulations/README.md) contains calculator-neutral structures
  and reciprocal-space path declarations;
- [`integrations/quantumespresso/`](integrations/quantumespresso/README.md)
  contains QE-native input examples, retained observations, and exact upstream
  snapshots; and
- [`integrations/vasp/`](integrations/vasp/README.md) contains VASP-native input
  and retained-observation examples.

Provider-native artifacts and historical snapshots are evidence or reference
material. Their presence does not authorize calculator execution or establish
scientific validation.
