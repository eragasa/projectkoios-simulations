# `QePw2Wannier90InputConfiguration`

Declares:

- `prefix`
- `outdir`
- `seedname`
- `spin_component`
- `mode`
- `write_amn`
- `write_mmn`
- `write_unk`
- `write_spn`
- `input_filename`
- `nnkp_filename`
- `nnkp_sha256`
- `nnkp_byte_size`
- `parent_nscf_saved_state_manifest_sha256`

The maintained interface requires `.amn` and `.mmn`, while optional UNK and
SPN output remains explicitly unimplemented.
