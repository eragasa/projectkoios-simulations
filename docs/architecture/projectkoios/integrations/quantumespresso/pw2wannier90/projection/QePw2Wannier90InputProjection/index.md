# `QePw2Wannier90InputProjection`

Fields:

- `rendered_input`
- `prefix`
- `outdir`
- `seedname`
- `nnkp_filename`
- `nnkp_sha256`
- `nnkp_byte_size`
- `parent_nscf_saved_state_manifest_sha256`
- `required_output_filenames`

These bind rendered native input to the exact `.nnkp`, parent NSCF saved-state
manifest, and required `.amn`, `.mmn`, and `.eig` output names.
