# `QePwInputFileAssembler`

The `assemble` action projects `PwDftSimulation.settings.calculation_type` into `ControlBlock.calculation_type`; accepts explicit optional `prefix`, `pseudo_dir`, and `outdir`; retains the simulation's exact `UnitCell`; and generates structure cards from that cell using caller-selected `atomic_positions_unit`, `cell_parameters_unit`, `coordinate_precision`, and `card_order` values. The silicon example selects `ATOMIC_POSITIONS (crystal)`, `CELL_PARAMETERS (angstrom)`, eight decimal places, and its explicit card order in `run.py`. Caller-supplied groups may not duplicate generated structure cards. Namelists precede cards, and the caller selects card order explicitly; documented `PW_CARD_NAMES` order is the deterministic fallback for omitted card names. This is deterministic model assembly and does not stage files or execute Quantum ESPRESSO.
