# `QeCelldm`

Immutable representation of the `celldm1`, `celldm2`, `celldm3`, `celldm4`, `celldm5`, and `celldm6` parameter family. Length and ratio values must be positive; angle cosines must lie strictly between `-1` and `1`. `has_shape_parameters` reports whether any value beyond `celldm1` is present.
