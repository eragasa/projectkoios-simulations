# `QeBravaisLattice`

Integer enumeration of every Quantum ESPRESSO 7.5 `ibrav` identity. `bravais_lattice_kind` maps each calculator identifier to its calculator-neutral convention.

Members: `free`, `cubic_primitive`, `cubic_face_centered`, `cubic_body_centered`, `cubic_body_centered_symmetric`, `hexagonal_trigonal_primitive`, `trigonal_rhombohedral_axis_c`, `trigonal_rhombohedral_axis_111`, `tetragonal_primitive`, `tetragonal_body_centered`, `orthorhombic_primitive`, `orthorhombic_base_centered`, `orthorhombic_base_centered_alternate`, `orthorhombic_one_face_base_centered`, `orthorhombic_face_centered`, `orthorhombic_body_centered`, `monoclinic_primitive_unique_c`, `monoclinic_primitive_unique_b`, `monoclinic_base_centered_unique_c`, `monoclinic_base_centered_unique_b`, and `triclinic`.
