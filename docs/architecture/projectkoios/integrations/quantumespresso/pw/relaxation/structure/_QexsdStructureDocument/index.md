# `_QexsdStructureDocument`

Private structural protocol for the existing parser result. It requires
`source_path`, `source_sha256`, `source_byte_count`, `qexsd_version`,
`producing_application`, `producing_application_version`,
`declared_unit_system_label`, `atomic_structure_alat`,
`direct_lattice_vectors`, `direct_lattice_source_label`, `atoms`,
`declared_atom_count`, `atomic_positions_source_label`, and `exit_status`.
