# `_QexsdNscfDocument`

Structural protocol for the immutable QEXSD fields consumed from the maintained
`ksdft2effmass` parser:

- `source_path`
- `source_sha256`
- `source_byte_count`
- `qexsd_version`
- `producing_application`
- `producing_application_version`
- `declared_unit_system_label`
- `k_points`
- `k_point_weights`
- `sampled_k_point_count`
- `k_point_source_label`
- `eigenvalues`
- `occupations`
- `eigenvalue_source_label`
- `band_count`
- `exit_status`

It is not a second XML parser or public scientific model.
