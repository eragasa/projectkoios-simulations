# `integrations.quantumespresso.saved_state`

Immutable evidence declarations, closed JSON loading, and exact-file
verification for the selected subset of a Quantum ESPRESSO `prefix.save` tree:

- `QeSavedStateCalculation`
- `QeSavedStateArtifactRole`
- `QeSavedStateArtifact`
- `QeSavedStatePseudopotential`
- `QeSavedStateManifest`
- `QeSavedStateManifestJsonCodec`
- `QeSavedStateManifestVerifier`
