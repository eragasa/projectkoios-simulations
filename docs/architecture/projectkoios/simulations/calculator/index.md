# `projectkoios.simulations.calculator`

This protected package owns calculator-neutral integration identity and exact
prepared calculator-input values. `CalculatorIntegrationId` selects one outward
provider namespace by stable slug. [`input`](input/index.md) owns rendered file
bytes, external requirements, neutral-to-native mappings, source correlation,
and canonical prepared-input records.

The package contains no executable paths, execution authority, provider
implementation objects, or scientific acceptance policy.
