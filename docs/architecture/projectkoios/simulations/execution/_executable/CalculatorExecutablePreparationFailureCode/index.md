# `CalculatorExecutablePreparationFailureCode`

`projectkoios.simulations.execution.CalculatorExecutablePreparationFailureCode`
is the closed mechanical failure vocabulary for exact executable preparation.
It distinguishes missing paths, symbolic links, non-regular files,
non-executable modes, byte-size mismatch, SHA-256 mismatch, and indeterminate
observation failure.

The codes express no retry, compatibility, or scientific-acceptance policy.
