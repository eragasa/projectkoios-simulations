# `projectkoios.simulations.dft.pw.nscf`

Calculator-neutral plane-wave DFT non-self-consistent-field namespace. No
public neutral NSCF request or integration contract has yet been accepted.
Quantum ESPRESSO-specific NSCF configuration, projection, and extraction remain
owned by `integrations.quantumespresso.pw.nscf`; this namespace does not claim
they are calculator-neutral.
